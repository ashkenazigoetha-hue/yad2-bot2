# Yad2 Car Search Bot 🚗

בוט טלגרם שמחפש רכבים ביד2 ושולח התראות על מודעות חדשות בזמן אמת.

## מה הבוט עושה

- מאפשר להגדיר חיפושי רכב (יצרן, דגם, מחיר, שנה, קילומטראז')
- סורק את יד2 בצורה אוטומטית כל כמה דקות
- שולח הודעת טלגרם מיד כשעולה מודעה חדשה שתואמת את החיפוש
- שומר היסטוריה כדי לא לשלוח את אותה מודעה פעמיים

---

## התקנה

### דרישות מקדימות
- Python 3.10+
- חשבון טלגרם + [יצירת בוט דרך BotFather](https://t.me/botfather)

### 1. שכפל את הפרויקט
```bash
git clone https://github.com/ashkenazigoetha-hue/yad2-bot2.git
cd yad2-bot2
```

### 2. התקן תלויות
```bash
pip install -r requirements.txt
```

### 3. הגדר משתני סביבה
צור קובץ `.env` בתיקיית הפרויקט:
```env
TELEGRAM_TOKEN=your_bot_token_here
POLL_INTERVAL_MINUTES=15
DATA_DIR=data
```

> לקבלת `TELEGRAM_TOKEN`: שלח `/newbot` ל-[@BotFather](https://t.me/botfather) בטלגרם.

### 4. הפעל
```bash
python bot.py
```

אם הבוט כבר רץ על המחשב שלך ואתה רוצה למשוך את הגרסה המתוקנת:


## פקודות הבוט

| פקודה | תיאור |
|-------|--------|
| `/start` | הצג תפריט ראשי + ה-Chat ID שלך |
| `/add_search` | הוסף חיפוש חדש (שאלות שלב אחר שלב) |
| `/my_searches` | הצג וניהל את החיפושים שלך |
| `/check_now` | בדוק מיד אם יש מודעות חדשות |
| `/my_id` | הצג את ה-Chat ID שלך |
| `/stop_all` | מחק את כל החיפושים |
| `/help` | עזרה |

---

## משתני סביבה

| משתנה | ברירת מחדל | תיאור |
|-------|-----------|--------|
| `TELEGRAM_TOKEN` | חובה | טוקן הבוט מ-BotFather |
| `POLL_INTERVAL_MINUTES` | `15` | כמה דקות בין כל סריקה |
| `DATA_DIR` | `data` | תיקייה לשמירת נתונים |
| `DATABASE_URL` | ריק (שמירה בקובץ) | כתובת PostgreSQL אופציונלית |
| `PROXY_URL` | ריק | Proxy אופציונלי לעקיפת חסימות |

## פתרון בעיות

**הבוט לא שולח מודעות חדשות:**
- בהרצה הראשונה הבוט מסמן את כל המודעות הקיימות כ"נראו" ולא שולח כלום — זה תקין. מהרצה הבאה ישלח רק מודעות חדשות.
- הרץ `/debug_now` לבדוק שהסריקה עובדת.

**מודעות ישנות נשלחות שוב:**
- הפעלה מחדש של הבוט עם אותו קובץ `data/searches.json` תמנע שליחה חוזרת.
- אם הקובץ נמחק — הבוט מתחיל מחדש ומסמן הכל כנראה לפני שישלח.

**הבוט לא מגיב:**
- ודא ש-`TELEGRAM_TOKEN` נכון בקובץ `.env`.
- בדוק את `logs/bot.log` לשגיאות.
