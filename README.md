# Yad2 Car Search Bot 🚗

בוט טלגרם שמחפש רכבים ביד2 ושולח התראות על מודעות חדשות בזמן אמת.

## מה הבוט עושה

- מאפשר להגדיר חיפושי רכב (יצרן, דגם, מחיר, שנה, קילומטראז')
- סורק את יד2 אוטומטית כל כמה דקות
- שולח הודעת טלגרם מיד כשעולה מודעה חדשה שתואמת את החיפוש
- שומר היסטוריה כדי לא לשלוח את אותה מודעה פעמיים

---

## התקנה מאפס

### שלב 1 — צור בוט בטלגרם

1. פתח טלגרם וחפש את [@BotFather](https://t.me/botfather)
2. שלח `/newbot`
3. תן שם לבוט (לדוגמה: `Car Hunter Bot`)
4. תן username לבוט שמסתיים ב-`bot` (לדוגמה: `MyCarHunterBot`)
5. BotFather ישלח לך **טוקן** — שמור אותו, תצטרך אותו בהמשך

### שלב 2 — שכפל את הפרויקט

```bash
git clone https://github.com/ashkenazigoetha-hue/yad2-bot2.git
cd yad2-bot2
```

### שלב 3 — התקן תלויות

```bash
pip install -r requirements.txt
```

### שלב 4 — צור קובץ `.env`

צור קובץ בשם `.env` בתיקיית הפרויקט עם התוכן הבא:

```env
TELEGRAM_TOKEN=הטוקן_שקיבלת_מ_BotFather
POLL_INTERVAL_MINUTES=15
DATA_DIR=data
```

### שלב 5 — הפעל

```bash
python bot.py
```

כשהבוט עולה תראה בטרמינל:
```
🚀 Bot started! Polling every 15 minutes.
```

## עדכון קוד קיים

אם הבוט כבר רץ על המחשב שלך ואתה רוצה למשוך את הגרסה המתוקנת:

```bash
git remote set-url origin https://github.com/ashkenazigoetha-hue/yad2-bot2.git
git pull
python bot.py
```

> קובץ `.env` לא נמחק ב-`git pull` — הטוקן שלך נשמר.

## פקודות הבוט

| פקודה | תיאור |
|-------|--------|
| `/start` | הצג תפריט ראשי + ה-Chat ID שלך |
| `/add_search` | הוסף חיפוש חדש (שאלות שלב אחר שלב) |
| `/my_searches` | הצג וניהל את החיפושים שלך |
| `/check_now` | בדוק מיד אם יש מודעות חדשות |
| `/my_id` | הצג את ה-Chat ID שלך |
| `/stop_all` | מחק את כל החיפושים |
| `/help` | עזרה |

---

## משתני סביבה

| משתנה | ברירת מחדל | תיאור |
|-------|-----------|--------|
| `TELEGRAM_TOKEN` | חובה | טוקן הבוט מ-BotFather |
| `POLL_INTERVAL_MINUTES` | `15` | כמה דקות בין כל סריקה |
| `DATA_DIR` | `data` | תיקייה לשמירת נתונים |
| `DATABASE_URL` | ריק (שמירה בקובץ) | כתובת PostgreSQL אופציונלית |
| `PROXY_URL` | ריק | Proxy אופציונלי לעקיפת חסימות |

## פתרון בעיות

**הבוט לא שולח מודעות חדשות בהרצה הראשונה:**
זה תקין — בהרצה הראשונה הבוט מסמן את כל המודעות הקיימות כ"נראו" ולא שולח כלום. מהרצה הבאה ישלח רק מודעות חדשות.

**מודעות ישנות נשלחות שוב אחרי הפעלה מחדש:**
ודא שקובץ `data/searches.json` קיים ולא נמחק — הוא שומר את המודעות שכבר נראו.

**הבוט לא מגיב:**
- ודא שקובץ `.env` קיים עם `TELEGRAM_TOKEN` תקין
- בדוק שגיאות בקובץ `logs/bot.log`
